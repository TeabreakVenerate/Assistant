# Systems, Automations & Scripts

This directory houses helper scripts that extend your local assistant.

### Common Use Cases:
1. **Google Calendar Sync:** Sync markdown schedules from `task_calendar.md` directly into Google Calendar via API.
2. **Notification Dispatchers:** Push morning agendas to Telegram, Discord, or WhatsApp.
3. **Ledger Aggregators:** Summarize monthly financial logs into spending charts.

See `push_schedule_template.py` for a starter template.
